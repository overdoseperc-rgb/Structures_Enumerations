# КТ №13 — Структуры и перечисления

## Вариант 1. Игральная карта

Проект выполнен на C# для .NET 10 и Microsoft Visual Studio.

## Структура проекта

- `Program.cs` — основная программа.
- `Suit.cs` — перечисление мастей карты.
- `Rank.cs` — перечисление достоинств карты.
- `Card.cs` — структура `Card` с полями `Suit` и `Rank` и переопределённым `ToString()`.
- `KT13_Variant1_PlayingCard.csproj` — файл проекта.
- `KT13_Variant1_PlayingCard.sln` — решение Visual Studio.

## Что выполнено

Создан массив из 5 игральных карт.

Продемонстрирована value-семантика структуры: элемент `cards[0]` считывается из коллекции в локальную переменную `copy`. После изменения `Rank` у копии исходная карта в массиве остаётся без изменений.

Реализован `Enum.TryParse<Rank>`:
- `"King"` — корректное значение, преобразование успешно.
- `"Joker"` — некорректное значение, преобразование возвращает `false` без исключения.
